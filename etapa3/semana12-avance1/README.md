# Avance #1 - Semana 12 (RF-10)

**Requirement:** RF-10 Monitoreo de sensores ambientales en sucursales.
Real-time monitoring of temperature, humidity and people-counting sensors. Actor: maintenance technician.

**Deliverables (web prototype oriented):**

1. UML class diagram: key monitoring classes and their relationships.
2. High-level architecture diagram: system components, how they connect and interact.
3. Closing questions answered.

**Flows the design must cover:**

- Normal: receive sensor data, show updated values on screen, store data automatically.
- Alternate: one or more sensors stop sending data, a warning is shown.
- Exception: internet connection fails, a warning message is generated.
